# Reeled Studios

Site oficial da **Reeled Studios**, estúdio brasileiro de videogames, com destaque para o **KartX**.

Site estático (HTML, CSS e JavaScript puros, sem build). Para ver localmente, abra o `index.html` no navegador.

- `index.html` — página única
- `assets/css/style.css` — estilo inspirado no menu do KartX
- `assets/js/main.js` — animações e interações
- `assets/js/tracks.js` — traçados das 13 pistas, extraídos do catálogo do jogo
- `assets/img/`, `assets/video/` — capturas e abertura do jogo
